# Klavitopia — información legal

Política de privacidad de Klavitopia, con el estilo de la app: `privacidad.html` (generada desde `docs/politica-de-privacidad.md` del repositorio privado del proyecto), `index.html` (redirige a ella) y el logo.

Se publica con GitHub Pages desde un repositorio público aparte (`klavitopia-legal`), porque el repositorio del proyecto es privado y Pages gratuito solo publica repositorios públicos. URL prevista: https://bettodatatech.github.io/klavitopia-legal/privacidad.html

Para actualizarla: edita `docs/legal/politica-<idioma>.md`, ejecuta `python3 tool/build_privacy.py` (regenera `web/privacidad.html`, `web/privacy-<idioma>.html` y las copias de la app) y copia los archivos de esta carpeta al repositorio público.
